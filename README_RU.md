## Описание

Интерактивное приложение для работы с неориентированными графами:

- Редактирование графа в текстовом виде с автоматической симметризацией рёбер.
- Визуализация графа с возможностью перетаскивания узлов и масштабирования (стандартная панель инструментов matplotlib).
- Расчёт минимального набора «крепостей», покрывающих весь граф (задача доминирующего множества) с учётом:
  - обязательных (красных) вершин,
  - желательных (оранжевых) вершин,
  - исключительных (фиолетовых) вершин,
  - групповых ограничений («минимум N из множества вершин»),
  - запрета на соседние крепости (три режима).
- Ручная проверка произвольного набора крепостей на корректность.
- Поддержка двух языков: русский и английский, переключение на лету.

Приложение использует библиотеку **PuLP** для точного решения ILP‑модели, что позволяет находить оптимальное покрытие для графов с сотнями вершин за несколько секунд.

## Установка и запуск

### Требования

- Python 3.8 или выше ([python.org](https://python.org))
- Установка зависимостей:

  ```bash
  pip install networkx matplotlib pulp
  ```

### Структура проекта

Скачайте файлы и расположите их в одной папке:

```directory
project_folder/
├── graph_app.py
├── localization.py
└── localization/
    ├── ru.json
    └── en.json
```

> **Важно:** папка с переводами должна называться **`localization`**. Если вы переименуете, измените переменную `lang_dir` в `localization.py`.

### Запуск

Из командной строки в папке проекта выполните:

```bash
python graph_app.py
```

При успешном запуске откроется главное окно приложения.

## Функциональность

### Основные возможности

- **Ввод графа** – левое верхнее текстовое поле (формат описан ниже).
- **Словарь имён** – сопоставление номера вершины и её названия (например, `817 : Bladeskeep`).
- **Обязательные вершины** – на случай если древо миссий требует крепость в определенной провинции.
- **Желательные вершины** – оптимизатор старается включить их в решение (при одинаковом количестве крепостей).
- **Исключительные вершины** – используются в режиме «разрешены только в исключительных» для соседних крепостей.
- **Групповые ограничения** – строка вида `ИмяГруппы: провинция1,провинция2,провинция3 : 1` означает «минимум 1 крепость на группу из вершин 762,761,759».
- **Ограничения на соседние крепости** – три режима ограничений на постройку крепостей в соседних провинциях.
- **Оптимизация** – кнопка «Найти оптимальное покрытие».
- **Ручная проверка** – введите список вершин (через пробелы, запятые или строки) и программа сообщит обо всех нарушениях.
- **Сохранение / загрузка конфигурации** – весь ввод (граф, имена, списки, группы, таймер, режим) сохраняется в `graph_config.json`.
- **Переключение языка** – кнопка со сменой надписи «English»/«Русский».
- **Панель инструментов** – стандартный тулбар matplotlib (лупа, панорамирование, сброс вида).

## Работа с графом

### Формат описания графа

Каждая строка: `<вершина> : <список соседей через запятую>`

- Пробелы игнорируются.
- Строки, начинающиеся с `#`, считаются комментариями.
- Граф неориентированный – программа автоматически добавит обратные связи (учтите это т.к. удалить провинцию и связи с ней будет проблематичнее - программа будет автоматически добавлять обратно исходя из связей, записанных в других вершинах. Чтобы избежать этого увеличьте таймер обновления графа).
- Вершины, упомянутые как соседи, но не имеющие собственной строки, будут помещены в секцию `# Unattended` (автоматически).

**Пример:**

```config
# Северные земли
779 : 777, 778, 780
778 : 358, 775, 777, 779
```

### Взаимодействие с визуализацией

- **Перетаскивание узлов** – зажать левую кнопку мыши на узле и двигать.
- **Панорамирование** – использовать кнопки на тулбаре (лупа с рукой) или правую кнопку мыши (если вы не отключили кастомное панорамирование; в текущей версии используется только тулбар).
- **Зум** – колесо мыши или кнопки на тулбаре.
- **Сброс вида** – кнопка «Home» на тулбаре.

## Типы вершин и ограничения

| Цвет | Роль | Влияние на оптимизацию |
| ------ | ------ | ------------------------ |
| 🔴 Красный | Обязательная крепость | Всегда включается в решение |
| 🟠 Оранжевый | Желательная крепость | Максимизируется их количество среди решений с минимальным числом |
| 🟣 Фиолетовый | Исключительная крепость | Может быть разрешена как соседняя (режим 1) |
| 🟡 Золотой | Обычная крепость | Выбирается алгоритмом при необходимости |
| 💗 Розовый | Крепость, входящая в групповое ограничение | Отдельный цвет для наглядности |

### Групповые ограничения

Синтаксис: `Название: вершина1, вершина2, ... : минимальное_количество`

**Пример:** `Falsemire: 762,761,759 : 1` – из трёх указанных вершин хотя бы одна должна быть крепостью.

### Режимы соседних крепостей

- **0 – Запрещены любые соседние** – ни одна пара смежных вершин не может одновременно быть крепостью.
- **1 – Разрешены только в исключительных** – если две смежные вершины – крепости, то хотя бы одна из них должна быть фиолетовой (исключительной).
- **2 – Без ограничений** – любые комбинации разрешены.

## Форматы файлов

### `graph_config.json`

Автоматически создаётся при сохранении. Содержит все данные из текстовых полей и настройки:

- `graph_config` – текст графа,
- `names_config` – словарь имён,
- `mandatory_list` / `preferred_list` / `purple_list` – списки вершин,
- `group_list` – групповые ограничения,
- `update_delay_ms` – таймер автообновления (мс),
- `neighbor_constraint_mode` – выбранный режим (0/1/2).

### `localization/ru.json` и `en.json`

Файлы перевода. При добавлении новых ключей нужно редактировать оба файла. Ключи, используемые в программе, перечислены в самих JSON‑файлах.

## Устранение неполадок

### Ошибка «файл локализации не найден»

Убедитесь, что папка называется **`localization`** (не `localisations`, не `locale`) и внутри лежат `ru.json`, `en.json`. Если вы переименовали, измените `lang_dir` в `localization.py`.

### Ошибка «PuLP not installed»

Установите PuLP: `pip install pulp`. Либо используйте только ручную проверку покрытия (оптимизация не будет работать).

### Граф отображается зеркально / неправильно

Используйте панорамирование и зум на тулбаре, чтобы повернуть/переместить вид. Также можно перемещать вершины вручную.

### Крепости не находятся или решение слишком медленное

- Для графов более 300 вершин ILP может работать минуты. Увеличьте `timeLimit` в `solve_with_pulp` (сейчас 300 секунд).
- Убедитесь, что обязательные вершины действительно могут покрыть граф – иначе решения нет.
- Групповые ограничения могут сильно усложнить задачу.

## Пример использования: настройки для Рожерии

В комплекте с программой вы найдёте несколько файлов, содержащих готовые входные данные для тега **Рожерия** (модификация Анбеннар). Эти файлы позволяют воспроизвести оптимальное покрытие крепостями, которое приведено в `Rogieria Solution.txt`.

### 1. Подготовка файлов

Убедитесь, что у вас есть следующие файлы (они перечислены находятся в папке **Examples**):

- `Adjacents.txt` – описание графа (список смежности)
- `Dictionary.txt` – словарь имён вершин (номер → название)
- `Mandatory.txt` – обязательные крепости (красные)
- `Preferable.txt` – желательные крепости (оранжевые)
- `Exceptional.txt` – исключительные крепости (фиолетовые)
- `Mandatory Group.txt` – групповые ограничения
- `Rogieria Solution.txt` – ожидаемый результат (для сверки)

### 2. Пошаговая загрузка в приложение

1. **Запустите программу** (`python graph_app.py`).

2. **Конфигурация графа**  
   Откройте файл `Adjacents.txt` (например, в Блокноте), выделите всё содержимое и скопируйте (Ctrl+A, Ctrl+C). В левой верхней панели «Конфигурация графа» вставьте текст (Ctrl+V).  
   > При необходимости программа автоматически добавит отсутствующие обратные связи.

3. **Словарь имён**  
   Скопируйте содержимое `Dictionary.txt` в поле «Словарь имен узлов (номер : имя)».

4. **Обязательные крепости**  
   Скопируйте `Mandatory.txt` в поле «Обязательные крепости (красные)».

5. **Желательные крепости**  
   Скопируйте `Preferable.txt` в поле «Желательные крепости (оранжевые)».

6. **Исключительные крепости**  
   Скопируйте `Exceptional.txt` в поле «Исключительные крепости (фиолетовые)».

7. **Групповые ограничения**  
   Скопируйте `Mandatory Group.txt` в поле «Групповые ограничения».

8. **Режим соседних крепостей**  
   В разделе «Ограничения на соседние крепости» выберите:  
   **«Разрешены только в исключительных (фиолетовых) вершинах»** – именно этот режим использовался в примере (см. последнюю строку `Rogieria Solution.txt`: *Neighbor fort mode: allow only in preferred (purple) vertices*).

9. **Применить конфигурацию**  
   Нажмите кнопку **«Применить конфигурацию»**, чтобы граф отобразился на панели справа. При необходимости отрегулируйте масштаб и положение (тулбар matplotlib).

10. **Оптимизация**  
    Нажмите кнопку **«Найти оптимальное покрытие»**.  
    Программа рассчитает минимальный набор крепостей с учётом всех введённых ограничений.

### 3. Сравнение с ожидаемым результатом

После завершения расчёта в поле «Результат» появится список выбранных крепостей. Сверьте его с содержимым `Rogieria Solution.txt`. Оба списка должны почти полностью совпадать (порядок и формулировки могут незначительно отличаться, но номера вершин и их статусы будут теми же).

Пример ожидаемого фрагмента:

```config
Selected forts:
229 (Bal_Mire) (mandatory)
358 (Coldrest) (exceptional)
725 (Entalenham) (mandatory)
...
```

### 4. Примечания

- Если вы хотите сохранить все введённые данные для последующего использования, нажмите **«Сохранить конфигурацию»** – будет создан файл `graph_config.json`. В следующий раз можно будет загрузить его кнопкой **«Загрузить конфигурацию»**.
- Файлы `Dictionary.txt`, `Mandatory.txt` и другие подготовлены с учётом синтаксиса программы – комментарии (строки, начинающиеся с `#`) игнорируются, вершины могут быть перечислены в любом удобном формате (по одному на строку, через пробелы или запятые).
- Решение, полученное программой, должно соответствовать приведённому в `Rogieria Solution.txt`, если вы используете те же исходные данные и режим ограничений.
