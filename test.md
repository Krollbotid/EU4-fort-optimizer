## Описание

Интерактивное приложение для работы с неориентированными графами:

- Редактирование графа в текстовом виде с автоматической симметризацией рёбер.
- Визуализация графа с возможностью перетаскивания узлов и масштабирования (стандартная панель инструментов matplotlib).
- Расчёт минимального набора «крепостей», покрывающих весь граф (задача доминирующего множества) с учётом:
  - обязательных (красных) вершин,
  - желательных (оранжевых) вершин,
  - исключительных (фиолетовых) вершин,
  - групповых ограничений («минимум N из множества вершин»),
  - запрета на соседние крепости (три режима).
- Ручная проверка произвольного набора крепостей на корректность.
- Поддержка двух языков: русский и английский, переключение на лету.

Приложение использует библиотеку **PuLP** для точного решения ILP‑модели, что позволяет находить оптимальное покрытие для графов с сотнями вершин за несколько секунд.

## Установка и запуск

### Требования
- Python 3.8 или выше ([python.org](https://python.org))
- Установка зависимостей:
  ```bash
  pip install networkx matplotlib pulp
  ```

### Структура проекта
Скачайте файлы и расположите их в одной папке:

```
project_folder/
├── graph_app.py
├── localization.py
└── localization/
    ├── ru.json
    └── en.json
```

> **Важно:** папка с переводами должна называться **`localization`** (именно так, без окончания «‑tion»). Если вы переименуете, измените переменную `lang_dir` в `localization.py`.

### Запуск
Из командной строки в папке проекта выполните:
```bash
python graph_app.py
```

При успешном запуске откроется главное окно приложения.

## Функциональность

### Основные возможности
- **Ввод графа** – левое верхнее текстовое поле (формат описан ниже).
- **Словарь имён** – сопоставление номера вершины и её названия (например, `779 : Whistlevale Center`).
- **Обязательные вершины** – без них решение невозможно.
- **Желательные вершины** – оптимизатор старается включить их в решение (при одинаковом количестве крепостей).
- **Исключительные вершины** – используются в режиме «разрешены только в исключительных» для соседних крепостей.
- **Групповые ограничения** – строка вида `ИмяГруппы: 762,761,759 : 1` означает «минимум 1 крепость из вершин 762,761,759».
- **Ограничения на соседние крепости** – три режима (радиокнопки).
- **Оптимизация** – кнопка «Найти оптимальное покрытие» запускает точное ILP‑решение.
- **Ручная проверка** – введите список вершин (через пробелы, запятые или строки) и программа сообщит обо всех нарушениях.
- **Сохранение / загрузка конфигурации** – весь ввод (граф, имена, списки, группы, таймер, режим) сохраняется в `graph_config.json`.
- **Переключение языка** – кнопка со сменой надписи «English»/«Русский».
- **Панель инструментов** – стандартный тулбар matplotlib (лупа, панорамирование, сброс вида).

## Работа с графом

### Формат описания графа
Каждая строка: `<вершина> : <список соседей через запятую>`
- Пробелы игнорируются.
- Строки, начинающиеся с `#`, считаются комментариями.
- Граф неориентированный – программа автоматически добавит обратные связи.
- Вершины, упомянутые как соседи, но не имеющие собственной строки, будут помещены в секцию `# Unattended` (автоматически).

**Пример:**
```
# Северные земли
779 : 777, 778, 780
778 : 358, 775, 777, 779
```

### Взаимодействие с визуализацией
- **Перетаскивание узлов** – зажать левую кнопку мыши на узле и двигать.
- **Панорамирование** – использовать кнопки на тулбаре (лупа с рукой) или правую кнопку мыши (если вы не отключили кастомное панорамирование; в текущей версии используется только тулбар).
- **Зум** – колесо мыши или кнопки на тулбаре.
- **Сброс вида** – кнопка «Home» на тулбаре.

## Типы вершин и ограничения

| Цвет | Роль | Влияние на оптимизацию |
|------|------|------------------------|
| 🔴 Красный | Обязательная крепость | Всегда включается в решение |
| 🟠 Оранжевый | Желательная крепость | Максимизируется их количество среди решений с минимальным числом |
| 🟣 Фиолетовый | Исключительная крепость | Может быть разрешена как соседняя (режим 1) |
| 🟡 Золотой | Обычная крепость | Выбирается алгоритмом при необходимости |
| 💗 Розовый | Крепость, входящая в групповое ограничение | Отдельный цвет для наглядности |

### Групповые ограничения
Синтаксис: `Название: вершина1, вершина2, ... : минимальное_количество`

**Пример:** `Falsemire: 762,761,759 : 1` – из трёх указанных вершин хотя бы одна должна быть крепостью.

### Режимы соседних крепостей
- **0 – Запрещены любые соседние** – ни одна пара смежных вершин не может одновременно быть крепостью.
- **1 – Разрешены только в исключительных** – если две смежные вершины – крепости, то хотя бы одна из них должна быть фиолетовой (исключительной).
- **2 – Без ограничений** – любые комбинации разрешены.

## Форматы файлов

### `graph_config.json`
Автоматически создаётся при сохранении. Содержит все данные из текстовых полей и настройки:
- `graph_config` – текст графа,
- `names_config` – словарь имён,
- `mandatory_list` / `preferred_list` / `purple_list` – списки вершин,
- `group_list` – групповые ограничения,
- `update_delay_ms` – таймер автообновления (мс),
- `neighbor_constraint_mode` – выбранный режим (0/1/2).

### `localization/ru.json` и `en.json`
Файлы перевода. При добавлении новых ключей нужно редактировать оба файла. Ключи, используемые в программе, перечислены в самих JSON‑файлах.

## Сборка в standalone‑приложение

Чтобы распространять программу как один `.exe` файл (без установки Python):

1. **Установите PyInstaller** (если ещё не установлен):
   ```bash
   pip install pyinstaller
   ```
2. **Перейдите в папку проекта** и выполните команду:
   ```bash
   pyinstaller --onefile --windowed --add-data "localization;localization" --hidden-import=pulp --name "GraphApp" graph_app.py
   ```
   > Для Linux/macOS замените `;` на `:`.
3. **Готовый файл** появится в папке `dist/GraphApp.exe`.

При первом запуске на Windows может потребоваться разрешение на выполнение – нажмите «Выполнить». Все зависимости (matplotlib, networkx, pulp) будут упакованы внутрь.

## Устранение неполадок

### Ошибка «файл локализации не найден»
Убедитесь, что папка называется **`localization`** (не `localisations`, не `locale`) и внутри лежат `ru.json`, `en.json`. Если вы переименовали, измените `lang_dir` в `localization.py`.

### Ошибка «PuLP not installed»
Установите PuLP: `pip install pulp`. Либо используйте только ручную проверку покрытия (оптимизация не будет работать).

### Граф отображается зеркально / неправильно
Используйте панорамирование и зум на тулбаре, чтобы повернуть/переместить вид. При необходимости можно сохранить позиции узлов (если вы добавите эту функцию, как описано в одном из обсуждений). В текущей версии позиции генерируются автоматически алгоритмом `kamada_kawai_layout`.

### Крепости не находятся или решение слишком медленное
- Для графов более 300 вершин ILP может работать минуты. Увеличьте `timeLimit` в `solve_with_pulp` (сейчас 300 секунд).
- Убедитесь, что обязательные вершины действительно могут покрыть граф – иначе решения нет.
- Групповые ограничения могут сильно усложнить задачу.

### При перетаскивании узлов граф «дёргается»
В текущей версии используется стандартный тулбар, а кастомное панорамирование отключено. Перетаскивание узлов осталось – оно должно работать плавно.
